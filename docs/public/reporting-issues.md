# 🐛 Reporting issues

[Public documentation](README.md) | [Repository preview](../../README.preview.md)

Use this repository's [Issues tab](https://github.com/CoC-MS/ALSO-Microsoft-Security-iOSandiPadOS/issues) for reproducible export/import problems and documentation or licensing corrections. Search existing reports first and choose the matching issue form.

| Include | Useful sanitized detail |
| --- | --- |
| Repository content | Commit/release, policy-set folder, exact filename or policy name, and affected resource type. |
| Device scenario | iOS/iPadOS version, BYOD versus corporate ownership, MAM-only versus enrolled, enrollment method, supervision, and user affinity where relevant. |
| Deployment | Import tool/version, selected workloads/options, prerequisite checks, and minimal reproduction steps. |
| Result | Expected versus actual behavior, whether reproduced in a test tenant, and relevant redacted error output. |
| Services | Relevant license/service configuration and whether Defender onboarding, compliance reporting, or CA evaluation is affected. |

> [!IMPORTANT]
> Public issues are visible to everyone. Do not attach tenant exports, credentials, tokens, certificates/private keys, customer details, tenant/user/device identifiers, group memberships or assignments, or unredacted logs/screenshots. Replace environment-specific values with placeholders.

For usage questions and implementation support, use the [support guidance](https://github.com/CoC-MS/security-template/blob/main/SUPPORT.md) linked by this repository's issue chooser.

Do not disclose exploitable vulnerabilities or sensitive security details in public issues. Use GitHub private vulnerability reporting **if enabled**, or your organization's established private disclosure channel. The local [SECURITY](../../SECURITY) file provides usage responsibilities and disclaimers; it does not specify a private reporting contact.
